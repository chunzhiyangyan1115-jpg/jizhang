iOS 快捷指令记账教程

返回

原理

快捷指令弹窗让你输入金额/备注，然后用 Safari 打开本应用的网址（带参数），应用自动记一笔。整个过程不经过任何服务器：参数只在你手机上的浏览器里处理。

下文中 你的网址 指你部署本应用的地址，例如 https://xxx.github.io/jizhang/index.html。

支持的网址参数

  • ?add=1&amount=35&note=午饭&cat=餐饮 直接记一笔（cat 可省略，按备注自动分类）
  • &type=income 记为收入；&date=2026-10-14 指定日期
  • ?add=1&note=xxx（不带金额）打开填写表单
  • ?quick=1 打开并聚焦快速输入框；?quick=1&text=午饭 35 预填

第一步：创建快捷指令「记一笔」

  1. 打开「快捷指令」App → 右上角 ＋ → 命名为「记一笔」。
  2. 添加操作 「要求输入」：类型选「数字」，提示「金额」。
  3. 添加操作 「要求输入」：类型「文本」，提示「备注（可空）」。
  4. 添加操作 「URL」，内容填：
    你的网址?add=1&amount=[插入变量：提供的输入(金额)]&note=[插入变量：提供的输入(备注)]
  5. （可选）若备注可能含 & # 等符号，在第3步后加「URL 编码」操作对备注编码，再把编码结果插入 URL。
  6. 添加操作 「打开 URL」。
  7. 运行后 Safari 顶部会弹出绿色提示「✅ 已记一笔 ¥35 餐饮」即表示成功。若没有提示，请在 Safari 中先打开一次本网址（让新版本生效），或检查 URL 中 amount= 后面确实插入了变量。也支持 #add=1&amount=35 写法；金额可写 35,5。
  8. 点「完成」。可在详情里「添加到主屏幕」或绑定「轻点背面」（设置→辅助功能→触控→轻点背面）。

更简单的版本：只放一个「URL」= 你的网址?quick=1 + 「打开 URL」，打开后直接输入「午饭 35」。

第二步：个人自动化（付款后提醒记账）

  1. 快捷指令 → 底部「自动化」→ ＋（新建个人自动化）。
  2. 选择 「App」 → 选择 支付宝 和 微信 → 勾选 「已关闭」（离开支付App时触发）。
  3. 选择 「立即运行」（iOS 17+；旧版本关闭「运行前询问」），关闭「运行时通知」可选。
  4. 操作：选择「运行快捷指令」→「记一笔」。

替代触发器：「电子钱包」/「交易」自动化（iOS 17+）仅对 Apple Pay 卡片交易生效，可把金额、商户作为变量直接传入 URL，无需手动输入——但微信/支付宝付款不会触发它。

从相册导入账单截图（离线识别）

  1. 在微信「账单」列表、支付宝「账单」列表，或付款完成后的「支付成功」页面截屏。
  2. 打开本应用 → 「导入」→ 「🖼 从相册导入账单截图」，可一次多选几张。
  3. 等待「正在识别… 40%」完成，在预览中核对金额/日期/备注/分类，取消勾选不需要的条目，点「导入所选」。已存在的记录会标为「重复」默认不勾选。

文字识别（OCR）完全在手机本地完成，截图不会上传到任何服务器。首次使用会从本站下载约 12MB 识别引擎并缓存，之后断网也可用。截图越清晰（不要裁剪得太小、不要用照片拍屏幕）识别越准；列表截图里没有年份时按今年计算，没有日期的按今天计算（预览中会提示「未识别日期」）。

局限（请知悉）

  • iOS 不允许读取微信/支付宝的付款金额，所以只能「半自动」：每次仍需手动输入金额。每次关闭微信也会触发（包括只是聊天），可在弹窗时取消。
  • 主屏幕图标现在会在 Safari 中打开本应用，与快捷指令「打开 URL」共用同一份 Safari 存储，所以快捷指令记录的账目会直接出现在这里。
    如果你之前已添加过主屏图标（旧版以独立 Web App 方式打开，数据与 Safari 隔离）：请先在旧图标里「设置→备份」导出 JSON，然后删除旧的主屏图标，再用 Safari 打开本网址，点「分享」→「添加到主屏幕」重新添加；若 iOS 26 显示「作为 Web App 打开」开关，请将其关闭。最后在 Safari 中导入备份（自动合并去重）。
  • Safari 可能在长时间（约 7 天）未访问某网站后清除其本地数据（主屏图标同样走 Safari 存储）。请定期导出备份。
  • 开启密码锁后，快捷指令打开应用需先解锁才会记录。
  • 账单导入是最可靠的「自动」方式：每月从微信/支付宝导出账单导入，重复记录会自动去重；截图识别可能把个别数字或商户名认错，导入前请核对（手动记的与账单里的条目时间不同，可能无法识别为重复，导入预览中可自行判断）。
